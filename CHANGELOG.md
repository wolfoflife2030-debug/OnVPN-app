# Changelog

## 0.1.0 — Android MVP source
- Added Kotlin Android app shell with On Vpn branding and Arabic UI.
- Integrated the official WireGuard tunnel library from Maven Central.
- Added WireGuard config parsing, VPN permission prompt, tunnel up/down handling, and visible state/error feedback.
- Added build/use instructions and explicit MVP limitations.
- Not yet production-ready; server management, split-tunnel UI, traffic counters, Windows client, and release QA remain future milestones.
